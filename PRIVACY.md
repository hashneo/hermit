# Privacy Policy for Hermit

**Last updated: July 2026**

## Overview

Hermit does not collect, transmit, or share any personal data with the developer or any third party.

## Data Storage

All data entered into Hermit — including account credentials, repository configuration, and RFC document content — is stored locally on your device. The developer has no access to this data at any time.

## Network Requests

Hermit makes network requests only to the GitHub, GitHub Enterprise, or Gitea server endpoints that you explicitly configure in Settings. These requests are made directly from your device using your own credentials and are subject to the privacy policies of those services.

## Credentials

Personal Access Tokens (PATs) are stored exclusively in the system Keychain on your device. They are never transmitted to the developer, never included in exported configuration files, and never leave your device except as authentication headers in requests to the server endpoint you configure.

## Local Server

Hermit runs a lightweight embedded server on your device to power the RFC document viewer. This server binds to the local loopback interface (localhost) only and is not accessible from the network.

## Analytics and Tracking

Hermit contains no analytics, crash reporting, advertising SDKs, or tracking of any kind. No usage data is collected or transmitted.

## Children's Privacy

Hermit does not knowingly collect any information from anyone, including children under the age of 13.

## Changes to This Policy

If this policy changes, the updated version will be published at this URL with a revised date.
